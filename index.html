Professional Games


These are some of the games that I've developed over the years.


Passa ou Repassa

Passa ou Repassa is a licensed mobile game based on the TV game show of the same name. It is a game that I've worked in LIGA FACENS and published by SBT Games. I was responsible for the main game core mechanics, such as the the Multiplayer implementation and some of the mini-games. It was developed using Unity Engine.


The game can be downloaded for android devices at Google Play and for iOS devices at App Store.



Mundo SBT

This is a Massive Multiplayer Online (MMO) game, developed in Unity, for a very prestigious television broadcast channel in Brazil, that I've worked for over 2 years. It was such a amazing experience that I've learnt a lot from multiplayer development, and to work with a huge team.

In this game I develop some of the gameplay features such as the Character Customization, Interaction System, Social Interactions, etc...; all of them with multiplayer integration.


Unfortunately the game was discontinued and is no longer available for downloads.



Achei! Hard

This is one of my favourites, I've made all the Programming and Game Design. It is a harder version of another game, that I also help develop.

In this game, each round you'll have to listen to a stuttering sound referring to a specific figure in the board, you score if you choose the correct answer. This is meant to measure and evaluate the effectiveness of external auditory canal (EAC).

It was made using Godot 3.2 for web. The game is available at Afinando o Cérebro, with a subscription plan.



Crystal Colors

This is a mobile game, available at Google Play Store for Android. In this game, I was responsible for the Google Play Services Integration with Godot 3.2, and some gameplay features.

Your goal is to touch in the crystal with the color that matches with the instructions on screen. It was based on the Stroop Effect.

It can be downloaded for free by the following link: Crystal Colors



Telefonista

That is my first game to be released at the "AFINANDO O CÉREBRO" platform.

Your goal is to listen to the phone call, and write in the blank fields who call, from who, and the following extension. This game estimulates the auditory background figure ability, and memory as well.

It was made using Godot 3.2 for web. The game is available at Afinando o Cérebro, with a subscription plan.


If you find yourself interested and want to see more of the games that I helped develop at ProBrain, you can contact me, or access the platform at Afinando o Cérebro
